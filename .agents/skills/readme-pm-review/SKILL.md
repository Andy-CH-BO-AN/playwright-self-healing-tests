# README PM Review

僅在使用者明確要求下列任一事項時使用：`README.md` 的 PM review、產品觀點的 README 可讀性回饋、product-oriented README rewrite suggestion，或只根據 README 內容提出 product prioritization idea。

## 必要 scope

- 先讀 `README.md`。
- 分析只根據 README 實際內容。
- 不可推測 README 未支持的 feature、roadmap item 或 user persona。

## 工作項目

1. 評估 first-time reader 是否能理解：product 是什麼、解決什麼 problem、誰會用、目前 project status、如何快速開始。
2. 建議 README 改善：哪些 section 過於 engineering-heavy、哪些資訊該提前、哪些 wording 該更 product-oriented，以及更清楚的 README structure。
3. 只根據 README 所述 capability 提出 product next step：未來 1–2 iteration 的 short-term priority、medium-term idea、不該現在優先的 idea，並說明 reason、user value、priority rationale。

## Output format

必須精確使用以下 heading：

- `## README 可讀性評估`
- `## README 改寫建議`
- `## 產品需求建議`
- `## 建議優先順序`
